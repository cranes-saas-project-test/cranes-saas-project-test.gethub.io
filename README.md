## الطريقة الأولى: فتح التطبيق مباشرة (الأسهل)
انقر نقرًا مزدوجًا على الملف التالي:
```

```
سيتم فتح التطبيق في متصفح الويب تلقائيًا.

1. افتح ملف serve.js باستخدام برنامج المفكرة
2. أو استخدم PowerShell:
